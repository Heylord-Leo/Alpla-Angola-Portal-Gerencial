## Status

All screenshots are currently **placeholders** (`.md` files with reproduction steps). No browser screenshots have been captured yet.

## How to Capture

Each `.md` placeholder file contains:
- **URL/Page**: Where to navigate
- **Role Required**: User role needed
- **Setup Steps**: Pre-conditions
- **Capture Steps**: Exact steps to reproduce
- **Expected Result**: What should be visible
- **Masking Requirements**: What to redact
- **Evidence Status**: Placeholder / Captured

## Naming Convention

- `SCR-{ID}_{description}.md` — Placeholder with capture instructions
- `SCR-{ID}_{description}.png` — Actual captured screenshot (when available)
